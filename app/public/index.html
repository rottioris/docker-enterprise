概要 — Overview

Enterprise Platform

A three-tier web application deployed with Docker Compose: an Nginx reverse proxy, a Node.js API, and a PostgreSQL database, isolated on a private bridge network with persistent storage.

手順 — How it works

Request lifecycle

  1. Client → Nginx. The browser hits port 80; Nginx is the only container publishing a host port.
  2. Nginx → App. proxy_pass http://app:3000 resolves the service name over the bridge network.
  3. App → PostgreSQL. Express runs SELECT NOW() using credentials injected as environment variables.
  4. Response. The DB timestamp travels back through the same path and is rendered on this page.
