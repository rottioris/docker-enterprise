01 — Resumen

Plataforma Empresarial

Aplicación web de tres capas desplegada con Docker Compose: proxy inverso Nginx, API en Node.js/Express y base de datos PostgreSQL, aisladas en una red bridge privada con almacenamiento persistente.

Repositoriogithub.com/rottioris/docker-enterprise
Entornonode:20-alpine · nginx:alpine · postgres:15-alpine
Redred_empresa (bridge) — solo se expone el puerto 80
Persistenciadb_data (volumen con nombre)

04 — Cómo funciona

Ciclo de vida de la petición

  1. Cliente → Nginx. El navegador entra por el puerto 80; Nginx es el único contenedor que publica un puerto en el host.
  2. Nginx → App. proxy_pass http://app:3000 resuelve el nombre del servicio a través de la red bridge.
  3. App → PostgreSQL. Express ejecuta SELECT NOW() con credenciales inyectadas como variables de entorno.
  4. Respuesta. La hora de la base de datos regresa por el mismo camino y se muestra en esta página.
